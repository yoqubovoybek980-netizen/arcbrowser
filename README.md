# ArcBrowser

Android uchun WebView asosidagi brauzer. Tablar, xatcho'plar, reklama bloklash, kompyuter versiyasi, yuklab olish.

## APK olish (Android Studio'siz)
1. GitHub'da yangi repo oching va shu papkadagi hamma fayllarni yuklang (`.github` papkasi bilan).
2. Repo > Actions bo'limida "APK yig'ish" ishga tushadi (yoki "Run workflow").
3. Tugagach, natijadagi `ArcBrowser-APK` artefaktini yuklab oling, zip ichida `app-debug.apk` bor.
4. Telefonda APK'ni oching (Sozlamalarda "noma'lum manbalardan o'rnatish"ga ruxsat bering).
